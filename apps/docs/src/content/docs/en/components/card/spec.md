## Overview

Card is a minimal surface container for grouped content. Elevated and outlined cards use elevation level 2 by default and level 8 on hover or while an owning drag interaction is active.

Selectable cards use an 8% state layer in their content color when `selected` is supplied. An activated card uses a primary 2px inner outline without a state layer.
