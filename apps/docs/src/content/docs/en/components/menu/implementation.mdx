## Basic usage

<DemoBlock title="Menu alignment" code={menuBasicDemoSource} language="vue">
    <MenuBasicDemo client:load />
</DemoBlock>

`RMenu` and `RMenuItem` provide an action-only anchored menu. The trigger is supplied through the `trigger` slot, items emit `click` when activated, and `align="start" | "end"` controls which logical edge of the trigger the menu aligns to.
