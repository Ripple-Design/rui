## Overview

`RCircularProgressIndicator` and `RLinearProgressIndicator` provide determinate and indeterminate progress feedback.
Circular indicators support 24 / 36 / 48 sizes, reversed direction, and indeterminate color cycling via `indicatorColors`, while linear indicators support buffer and reversed layouts.
