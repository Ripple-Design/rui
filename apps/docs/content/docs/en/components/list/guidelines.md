- Keep the primary label concise; use supporting and tertiary text only when the information merits a two- or three-line row.
- Use `action` for buttons and `href` for navigation. Keep a row static when it only presents information.
- Trailing content in an action row must be presentational. Compose a static row when it needs an independent interactive control.
