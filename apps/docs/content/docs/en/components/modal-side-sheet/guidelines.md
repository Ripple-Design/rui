## Usage guidelines

Use `RModalSideSheet` for contextual flows that should keep the user anchored in place while still blocking the background, such as editing settings, reviewing details, or confirming side-panel tasks.

Disable backdrop or Escape dismissal only when the sheet must resolve explicitly through actions inside the panel.
