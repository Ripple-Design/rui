## Basic usage


::demo-block{title="Icon button states" demo="IconButtonBasicDemo" language="vue"}
::


`RIconButton` is the icon-only companion to `RButton`. Use it for single actions, keep the icon decorative, and pass a descriptive `label` so assistive technology can announce the control correctly.
